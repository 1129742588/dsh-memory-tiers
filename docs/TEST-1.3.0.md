## 失败时优先看的日志关键词

```
BOOT_DONE / BOOT_FAIL / BOOT_MISSING    装载
INJECT_ON / INJECT_OFF / INJECT_FAIL    注入
CLASSIFY n/n                            分类批次
DIGEST[l1] / DIGEST[l2]                 分流
DIGEST_NO_MODEL / DIGEST_FALLBACK       模型不可用时的降级
VEC_LOAD_FAIL / VEC_ITEM_BAD            向量加载
FUSE_DUP / FUSE_UPDATE / SUPERSEDE      融合
FORGET_SUMMARY / DL1_TRIM               遗忘
ORGINIZE ok … ms                        单轮整理总耗时
```
